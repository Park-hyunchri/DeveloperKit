## 자동 버전 정책

- 운영 배포는 Git 태그 `vMAJOR.MINOR.PATCH`를 버전 기준으로 사용한다.
- 빌드·게시 명령에서 `/p:Version=<태그 버전>`과 커밋 정보를 주입한다.
- 태그가 없는 빌드는 `<기준버전>-preview.<빌드번호>` 형식의 시험용 버전으로 구분한다.
- 자동화는 `.sln`, `.csproj`, NuGet 구성을 수정하지 않는다.
