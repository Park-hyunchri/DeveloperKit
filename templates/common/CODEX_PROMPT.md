# Codex 작업 프롬프트

아래 내용을 새 작업 요청에 프로젝트 상황과 함께 사용한다.

```text
먼저 AGENTS.md와 관련 문서를 읽고 현재 프로젝트 유형과 Git 상태를 읽기 전용으로 분석해줘.

파일 변경 전 다음 항목을 설명하고 승인을 기다려줘.
1. 원인
2. 수정 파일
3. 영향 범위
4. 테스트 방법
5. 빌드 영향 범위

승인 후 기존 구조와 코딩 스타일을 유지하며 최소 수정해줘. 불필요한 using 정리, 자동 포맷, 리팩터링, 네이밍·주석 변경은 하지 마. 프로젝트 소스, .sln, .csproj, NuGet, 빌드 설정 변경은 별도 승인 없이는 하지 마.

작업 후 빌드·테스트 결과, git diff, git status를 보고하고 WORKLOG.md를 갱신해줘. CODEX_HANDOFF.md 갱신 필요 여부도 확인해줘. Commit과 Push는 내가 명시적으로 요청할 때만 수행해줘.
```
